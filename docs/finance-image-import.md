# Finance 免费本地截图文字识别

Finance → 导入与同步 → 选择持仓截图。

- 使用开源 Tesseract.js（Apache-2.0）在浏览器本地 OCR，**不需要任何付费模型 API Key**。
- 首次识别需要联网下载 Tesseract.js 和简体中文 + 英文识别语言包。运行过程占用浏览器 CPU/内存，移动端可能较慢。
- 截图不发送到 WeiS 服务器或视觉 AI 提供商；OCR 库和语言包从公共 CDN 下载（网络请求会联系 CDN）。
- 支持 6 MB 以内的 PNG/JPG/WebP。
- 只把截图中有明确六位代码的项目列为候选；份额及单位成本**默认留空**，避免把市值、净值等数字误导入持仓。
- 必须核对代码、股票/ETF或场外基金的类型，并补全份额与单位成本，点击“确认导入”后才会覆盖相同代码的本地持仓。
- 导入后仍需单独手动点击“上传到云端”才能备份到 Supabase。

## 注意事项
纯 OCR 只识别文字，不能保证准确理解复杂截图表格、列之间的对应关系。若未提取出代码，请在“原始识别文字”中检查，并使用手动添加。

不需要设置 FINANCE_OCR_PROVIDER、DASHSCOPE_API_KEY、ARK_API_KEY、MOONSHOT_API_KEY 或 OPENAI_API_KEY。本地识别不调用这些服务；原有付费截图识别服务端路由已删除。

## 验收
- 使用清晰的含6位基金代码的测试截图，确认提取候选代码；
- 确认数量与成本留空，不会自动误填；
- 填写数量、成本并确认，持仓正确更新；
- 删除草稿、取消识别不更改现有持仓；
- 检查无网络或语言包下载失败时的提示。
