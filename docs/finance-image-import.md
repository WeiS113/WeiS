# Finance 截图识别导入（PR #4）

功能：用户在 Finance 页面选择基金或券商持仓截图，服务端调用视觉模型提取**可见的六位证券代码、类别、持有份额/股数和单位持仓成本**。前端以草稿展示，必须人工核对与点击确认才保存到浏览器本地持仓。

## 启用方法

1. 在 Vercel 对 WeiS 项目的设置中打开 Environment Variables。
2. 新增 **OPENAI_API_KEY**，输入自己的 OpenAI API Key。该变量只能设置在服务器端，**不要加 NEXT_PUBLIC_ 前缀**，也不要提交到 GitHub。
3. 可选设置 FINANCE_OCR_MODEL（默认 gpt-4.1-mini）。
4. 重新部署，然后登录 WeiS，进入 Finance，选择截图。
5. 核对识别结果的代码、份额和单位成本，确认后导入。相同代码会覆盖当前浏览器的持仓，且仍需通过已有的手动「上传到云端」才会同步到 Supabase。

安全说明：请先遮盖账户号、姓名等隐私信息；图片将传送至 OpenAI API 进行识别。本服务端接口限制已登录用户、图片格式和文件大小（4 MB），没有保存原图，但第三方服务的数据处理仍按对应服务条款执行。导入失败或识别不确定时不要猜测数值，请人工填写。

## 验收清单

- Vercel build 成功，且服务器配置 OpenAI API Key。
- 用不含隐私信息的测试截图核对基金和股票的代码、份额及成本。
- 验证模糊/遮挡/缺少成本的图片会要求手动修改，而非默默填错。
- 验证取消和删除草稿不影响现有本地持仓。
- 验证确认导入后同代码覆盖、其他代码保留。
- 验证新持仓不会自动上传云端，直到用户明确点击上传。

## 图片识别服务商配置

在 Vercel 的 Environment Variables 设置以下服务端变量（二选一配置供应商，不要加 NEXT_PUBLIC_）：

| 服务 | FINANCE_OCR_PROVIDER | 密钥变量 |
| --- | --- | --- |
| 阿里云百炼千问视觉 | qwen | DASHSCOPE_API_KEY |
| 火山方舟豆包视觉 | doubao | ARK_API_KEY |
| Kimi（Moonshot） | kimi | MOONSHOT_API_KEY |
| OpenAI | openai | OPENAI_API_KEY |

可选 FINANCE_OCR_MODEL 指定控制台已开通、支持图像输入的具体模型名。不同地域、账户开通情况可能不一样。腾讯元宝普通产品的会员或聊天额度不等于腾讯混元开发者 API；目前尚未接入混元的认证流程。

截图识别结果必须经本人核对再提交；图片会发送到所选服务商。API Key 由站长自行获取，不要发到聊天中或提交到仓库。

## 新版基金展示

Finance 使用「我的持仓」「自选与搜索」「导入与同步」三个分区，以减少混乱。

基金历史净值 API 现在增加了第二数据来源作为备用。盘中参考估值使用 FundValuationLast 接口，**部分基金（尤其主动权益基金）可能返回 null**。页面会显示「暂无」，不会用已公布净值伪装成实时估值。估算只作参考，不纳入按官方净值计算的持仓盈亏。
