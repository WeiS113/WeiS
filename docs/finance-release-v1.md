# Finance v1 交付说明

## 已交付
- 网站首页 Finance 入口（路径：`/finance`）
- 股票 / ETF 和场外基金的名称与代码搜索、自选列表、刷新
- 自选持仓数量、单位成本、参考市值、浮动盈亏
- 股票 / ETF 日线和周线图，场外基金历史单位净值图
- 当前浏览器本地保存，JSON 导入与导出备份
- 可选 Supabase 云端手动备份及恢复（需先执行 SQL）

## 首次使用
1. 登录原 WeiS 网站，进入首页 Finance 模块。
2. 在搜索框输入股票名称、基金名称或 6 位代码，选择搜索结果或按代码添加。
3. 根据实际持仓填写份额、股数和单位成本；无需持仓时可将数量设为 0。
4. 通过「导出本地备份」保存持仓，以免浏览器数据清理导致丢失。
5. 如需跨设备恢复，先在 Supabase SQL Editor 审核运行 `supabase/finance.sql`，再使用上传 / 恢复按钮。

## 发布注意
- 本版本为**个人试用版**。Vercel 构建成功仅意味着构建通过；第三方数据接口的实时可用性、报价正确性、基金净值日期和授权使用条款还没有经过完整人工验收。
- 股票 / ETF 价格**可能延迟**，基金只显示最新公布的历史净值，**不是盘中估值**。
- 行情不可用时显示「—」而不虚构报价。持仓盈亏不含手续费、分红或税费。
- 云备份和恢复需手动操作，目前没有自动双向同步；云端数据库未建表时不会影响浏览器本地自选。
- 不提供交易和投资建议。请不要仅依据本工具报价作出交易决定。
